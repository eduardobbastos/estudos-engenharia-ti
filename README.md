# Estudos de Engenharia de TI — Arquitetura de Software

> **Documento consolidado:** [`SKILL.md`](./SKILL.md)

Este repositório contém o estudo consolidado de alta coesão, baixo acoplamento,
MVC, padrões GoF, DI, MVVM, Clean/Hexagonal, EDA, CQRS, DDD, Observabilidade e
Pragmatismo — com visões de Engenharia de Software e DevOps, e um pseudo-algoritmo
funcional para avaliação de codebases por agentes de IA.
